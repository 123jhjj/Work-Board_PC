# Work-Board (PC)

Work-Board 근무표/작업 일정 관리자 도구 — Windows용 데스크톱 버전입니다.

## 다운로드

[Releases](https://github.com/123jhjj/Work-Board_PC/releases/latest) 에서 최신 설치 파일(`.exe`)을 받아 실행하세요.

## 안내

- 이 저장소는 배포용 설치 파일만 제공합니다 (소스 코드는 포함되어 있지 않습니다).
- 데이터는 GitHub의 `Work-Board_json` 저장소(`schedule.json`)와 동기화되며, 저장 즉시 모바일 앱에도 반영됩니다.
